}}'''0.6.2.2''' is a minor update to the game released on 25 June 2022.<ref>[https://store.steampowered.com/news/app/739630/view/3334367690118116119 Truck Overhaul | Hotfix v0.6.2.2 (on Steam)]</ref> This update removes the increased spawn chance for new ghost types and fixes bugs. The update was pulled and re-released to fix an issue with the game appearing as a trial version.

== Changes ==
*Removed increased spawn chance for new ghost types ([[Deogen]], [[Moroi]], [[Thaye]])

== Bug fixes ==
* Fixed an issue where some languages were getting the same responses on the spirit box and Ouija board for all questions asked
* The Thaye will now answer questions correctly
