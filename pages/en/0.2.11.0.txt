}}'''0.2.11.0''' is a minor update to the game released on 21 July 2021.<ref>https://discord.com/channels/435431947963990026/661365069006897154/867389020644048958</ref> This update makes several minor changes to gameplay and fixes bugs.

== Changes ==
=== Ghosts ===
{{Main|Ghost}}
;[[Mare]]
*Can no longer turn lights on

;[[Yurei]]
*Now has an additional ability to lower players' sanity

=== Hunts ===
{{Main|Hunt}}
*Microphone volume required for the ghost to hear a player has been increased slightly

=== General ===
*The High volumetric lighting setting has been removed, with the Medium setting renamed to High

== Bug fixes ==
*Fixed a bug where the Sound Sensor graph bars could go higher than the monitor
*Fixed a bug where the ghost could always hear host players if they were talking when push to talk was turned on
*Fixed a bug where the Thermometer wouldn't always give values for the correct room
*Fixed a bug where disconnecting from server timeout on the main menu gave no error message
*Fixed a bug where the language selection and photo sensitivity warning didn't show until you reloaded the main menu
