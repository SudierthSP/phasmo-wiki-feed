= 天氣 =
<blockquote>''「每次你開始簽約時，地點都會有不同的天氣，增加新的遊戲層次，讓每份合約都感覺獨特。溫度的變化會使尋找鬼魂的位置變得更加困難，雨                            或風會損害你的聽力，濃霧會降低能見度。」''</blockquote><blockquote>—恐鬼症噩夢更新公告[https://store.steampowered.com/news/app/739630/view/4624626247919023465 <sup><nowiki>[src]</nowiki></sup>]</blockquote>'''天氣'''是一種旨在增強遊戲玩法並影響地圖內溫度的機制。

== 机制 ==
目前游戏内共有八种天气。
如果在游戏设置中选择随机天气，那么将从除了血月天气以外的七种天气中随机选择一种，概率相等。第八种天气血月有 2% 的概率替换所选天气。
不同天气会带来不同时听觉和视觉效果。

天氣分為四組[[温度|溫度]]。從最熱到最冷：

* 日出
* 晴天、大霧、血月
* 小雨、暴雨、颳風
* 下雪

這會影響玩家找到[[鬼魂]]的方式；天氣變暖意味著鬼所在的平均室溫會比天氣寒冷時稍高。

在室內，天氣的影響受到抑制：噪音幹擾（除了偶爾的雷聲）會安靜下來，霧和降雨的視覺效果也不會進入室內。然而，天氣因素在[[林风营地|林風營地]]，[[枫林营地|楓林營地]]和[[格拉夫顿农舍]]的部分区域中發揮重要作用，因為這些[[地图|地圖]]或区域是露天的。

== 日出 ==
[[File:Sunrise MapleLodge.png|alt=|thumb|400x400像素|[[枫林营地|楓林營地]]小屋處在日出天氣下俯瞰湖泊。]]
太陽正在地平線上升起（它實際上並沒有移動），將金色的光線投射到[[地图|地圖]]上，這可能會改善某些區域的照明。深藍色的天空沒有一絲雲彩。

'''照明：'''良好

'''能见度：'''高

'''噪音幹擾：'''低

'''溫度：'''16°C


== 晴天 ==
[[File:Clear 0.9.png|thumb|400x400px|[[里奇维尤路房屋|里奇維尤路房屋]]的晴天天氣。]]
「標準」的天氣類型，不會為遊戲玩法添加任何附加功能。周圍很昏暗，天空幾乎是漆黑的。

'''照明：'''差

'''能见度：'''高

'''噪音幹擾：'''低

'''溫度:'''13°C

== 大霧 ==
[[File:Fog 0.9.png|thumb|400x400px|[[枫林营地|楓林營地]]的大霧天氣。]]
[[地图|地圖]]被濃霧覆蓋，視線模糊。霧在建築物內消散，但室外的霧氣可能會妨礙玩家透過[[摄像机|攝像機]]在戶外進行夜視觀察。

'''照明：'''適中

'''能见度'''：差

'''噪音幹擾：'''低

'''溫度:'''13°C

== 血月 ==
这种天气提供了红色的天空和小雨。鬼魂在猎杀过程中的移动速度提高 15%，被动理智消耗速度提高 100%，[[合约]]报酬增加 10%。

'''照明：'''适中

'''能见度：'''高

'''噪音幹擾：'''中等

'''溫度:'''13°C

== 小雨 ==
[[File:Tanglewood lightrain 0.9.png|thumb|400x400px|[[坦格伍德街房屋]]的小雨天氣。]]
這種天氣類型會帶來適度的降雨，從而產生一些額外的噪音。火焰不受雨水影響。

'''照明：'''適中

'''能见度：'''高

'''噪音幹擾：'''中等

'''溫度：'''8°C

== 暴雨 ==
[[File:Grafton heavyrain 0.9.png|thumb|400x400px|[[格拉夫顿农舍|格拉夫頓農舍]]的暴雨天氣。]]
降雨和雷聲引起巨響，地圖被黑暗籠罩。

除了三級[[点火器|點火器]]和三級[[火光]]外，其餘不能在雨中點燃。當受雨影響的點火器或火光在室內點燃並帶到室外時，它會立即熄滅。

在這種天氣下，玩家無法在[[枫林营地|楓林營地]]或[[林风营地|林風營地]]點燃營火。如果[[鬼魂房间|鬼魂房間]]在外面並且沒有第三級火光， 那麼在這些[[地图|地圖]]上「讓[[鬼魂]]吹熄蠟燭」的目標可能會很困難。

'''照明：'''差

'''能见度：'''中

'''噪音幹擾：'''高

'''溫度：'''8°C

== 颳風 ==
[[File:Strong wind 0.9.png|thumb|400x400px|[[柳树街房屋|柳樹街房屋]]的颳風天氣。]]
這種天氣類型使周圍的樹木發出巨大的噪音。風使樹葉沙沙作響，是相當吵鬧的天氣類型。頭頂上的雲層很快就飄過，但除此之外，這種天氣類型看起來與晴朗相似。

'''照明：'''差

'''能见度：'''高

'''噪音幹擾：'''適度

'''溫度：'''8°C

== 下雪 ==
[[File:Lightsnow 0.9.png|thumb|400x400px|[[柳树街房屋|柳樹街房屋]]下雪天氣。]]
常有雪花從天上飄落，但雪並不會積在地上。[[地图|地圖]]周圍籠罩著一層薄霧。較低的環境溫度將導致整個[[地图|地圖]]上出現冰冷的呼吸，這可能會掩蓋尋找[[鬼魂房间|鬼魂房間]]的主要線索之一。如果游戏开局快速地找到鬼房，可以通过较晚打开电闸的方式，更快地获取[[刺骨寒温]]证据。

'''照明：'''適中

'''能见度：適中'''

'''噪音幹擾：'''低

'''溫度：'''5°C
