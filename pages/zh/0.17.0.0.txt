}}'''0.17.0.0'''即'''玩家角色更新'''，是于2026年5月5日发布的重大更新。<ref>[https://www.kineticgames.co.uk/news/phasmophobia-player-character-update-01700 ''Phasmophobia - 玩家角色更新 0.17.0.0''. 2026年5月5日.]</ref><ref group="note">官方Kinetic Games合作伙伴于2026年5月4日获得了抢先体验密钥。</ref> 此更新添加了新的[[玩家]]模型和动画，以及用于自定义这些模型的新装饰物。

== 新增内容 ==
*'''角色：''' 12个全新的、质量更高的角色模型（6男6女），附带角色简介、可调整的发色等。
*'''[[装饰物]]：''' 为游戏角色增添大量可用的装饰：外套、衬衫和裤子，均有多种颜色选项。为 声望和活动特定成就提供独特的衬衫。还可使用穿孔、帽子和眼镜等配饰。''注意：所有装饰物要么在游戏中解锁，要么用游戏内货币购买。''
*'''动画：''' 除了新的角色模型外，与装备、物品和环境的互动现在将具有角色动画。死亡时，还会看到新的死亡动画。
**PC和VR玩家可以通过选项菜单中的“沉浸式动画”开关（如下所示）启用/禁用新的第一人称死亡动画。如果禁用（默认状态），新的死亡动画将以第三人称视角呈现。
[[File:ImmersiveAnimations.png|center|500px]]
*'''玩家[[手表]]：''' 角色模型上添加了一块手表，可以在合约期间监测玩家的理智值并记录时间。玩家可以在左手为空时按住使用按钮，或者打开[[日志]]查看手表。如果理智监视器禁用，手表将不会显示理智值，也不会被视为用于鬼魂能力的电子设备。
**对于VR玩家，手表将始终可见，只需抬起左手即可查看。
*'''诅咒之谷装饰物：''' 诅咒之谷的装饰物奖励现已对所有玩家开放。诅咒之谷面具、T恤和项链可以在定制商店内装备。

== 更改内容 ==
*'''[[身份卡]]：''' 身份卡和徽章现在在定制商店菜单中装备和更换，而不是在主菜单。
*'''死亡房间：''' 移除玩家被鬼魂杀死后进入的房间，玩家现在会无缝过渡到死亡状态。
*'''玩家[[手册]]：''' 日志现在在使用时会出现在游戏中，而不是作为一个单独的UI元素。
*声望上限提高至4000。
**''注意：声望20级之后没有额外的解锁内容。''
*所有门都增加了物理效果，这意味着玩家松手后门会继续移动。
*手电筒现在将握在玩家的左手中，并且可以在右手为空时丢弃。
*设备（例如三脚架）现在可以站立放置。
*所有物品现在都会显示在角色模型上，而不是在未装备时隐形。
*2级录音机现在包含在“只有音频”每周挑战中。
*最低FOV选项现在是70，而不是60。默认设置保持为70。
*VR特定更改：
**移除装备腰带，所有物品现在都放置在角色模型上。
**传送移动圆圈现在将渲染在其他物体之上，并且在玩家体力满格按下传送按钮之前不可见。

*修复妖怪能在过远距离听到八音盒的问题。
*修复巨灵能吸取其上下楼层房间内玩家理智值的问题。
*修复VR中，玩家死亡后仍能看到其手册的问题。
*修复VR中导致玩家手部颤抖的问题。
*修复VR中难以从货车墙壁上捡起通灵盒的问题。
*修复VR中导致盐随玩家身体而非手部旋转的问题。
*修复VR中玩家可以在未选择传送抓取时与物体交互的问题。
*修复VR中玩家无法在休息室滚动浏览日志的问题。
*修复VR中玩家在使用传送移动时似乎会滑下楼梯的问题。
*修复VR中玩家可以隔着墙壁抓取物品的问题。
*修复VR中导致3级火源拿反的问题。
*修复VR中导致3级火源在多人游戏中悬浮在半空的问题。
*修复VR中导致玩家能在教程结束时传送出货车并跳过区域的问题。
*修复VR中难以与UI元素交互的问题。
*修复VR中导致门将玩家推至一旁的问题。
*修复VR中导致1级头戴式装备在查看闭路电视时从玩家身上脱落的问题。
*修复VR中导致玩家模型与其位置错位的问题。
*各种其他修复和改进。

== 已知问题 ==
*玩家在死亡过程中无法使用手册。
*如果在动画中途丢弃装备，“使用”动画可能会继续。
*在定制菜单中帧率会下降。
*通过其他玩家的1级头戴式装备查看闭路电视时，玩家将不可见。
*使用1级拍照相机时，手电筒会留在玩家手中。
*摄像机在使用中切换掉时可能会离开玩家。
*玩家死亡后，角色模型的眼睛将睁大。
*自定义难度设置“门初始为打开状态”仅适用于Tanglewood。
*奔跑或蹲伏时，脚步声音频无法与玩家速度正确匹配。
*玩家手持物品时可以抵住门使其关闭。
*VR和非VR玩家听不到彼此的脚步声。
*各种细微的视觉不一致问题。

''以下问题以及其他已知漏洞将在2026年5月12日发布的《恐鬼症》下一次更新中修复：''
*在拾取动画期间放置的物品将被放置在先前放置的位置。
*在发型定制屏幕上按取消会将发型应用到先前选择的角色上。
*幽霊的门关闭能力无法完全关闭门。
*如果玩家选择的徽章只有两个解锁项中的一个，某些ID卡徽章图标会变成白色。
*手持道具时抓取手电筒会导致手电筒被握持在玩家脚边。
*梅格·马尔斯戴帽子时头发是秃的。
*通灵板和诅咒镜会侧向掉落而不是平放在地上。
*手持塔罗牌时门无法正确打开。
*如果在蹲伏状态下被复活，角色骨架会显示错误。
*玩家蹲伏时头戴式装备会视觉卡顿。
*玩家旋转时装备会视觉卡顿。
*3级摄像机在右侧遮挡过多屏幕。
*死亡时玩家模型的布娃娃效果超出预期。
*更正“猎物”和“郊区居民”的描述。
*动态ID卡和徽章将正确显示。
*VR玩家蹲伏时双脚会陷入地面。
*VR玩家无法打开里奇维尤法院10号楼上楼走廊左侧的壁橱门。

''作为同一更新的一部分，我们还将进行以下更改：''
*移除装备切换动画以实现即时切换。
*盐将立即放置，而不是在动画结束后放置。
*装备将移近屏幕以便于阅读。
*玩家头部旋转现在将限制上下看的角度以适用于多人游戏（本地游戏仍然没有限制）。
*各种其他视觉和游戏性调整与改进。
